## NBA GRAPH NETWORK

Basketball is like a social network. With this overlap, I was curious if we could model an NBA teams offense through a network. Using this structure, we can analyze how do NBA offenses's differ between one another. Whether that's through a greater load to their star players, or an emphasis on a specific location on the court. When pulling in temporal data, from playoffs to different season, we can quantify if a team's offense changes over time and how.
